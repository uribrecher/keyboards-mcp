# Roland JUNO-X documentation

This project's JUNO-X MIDI/parameter mapping is derived from Roland's official
documentation. Those manuals are © Roland Corporation and are **not redistributed
in this repository**. Download them from Roland's official sources:

- **JUNO-X Owner's Manuals & MIDI Implementation** —
  https://www.roland.com/global/support/by_product/juno-x/owners_manuals/
- Reference Manual, Parameter Guide, and MIDI Implementation are listed there.

The notes in this directory (`juno-x-midi-arch.md`, `roland-dt1-rq1-keyboards.md`)
are our own analysis derived from those manuals and cite them by section/page.
