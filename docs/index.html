keyboards-mcp

An MCP server that lets an AI agent control hardware MIDI keyboards — read and change synth parameters, load programs and songs, with pluggable model support and a mock device for hardware-free development.

★ View on GitHub Read the docs
What it does

Drive real synths from an AI agent

Supports Nord Electro 5D, Roland JUNO-X, and Prophet-6 with model auto-detection. Tools are thin wrappers — each keyboard device owns its logic. A connections broker manages MIDI port leases so concurrent agent sessions don't collide, and an Electron mock runner lets you develop without hardware.

Connect & discover
connect_to_keyboard, list_midi_devices, is_connected
Read & set parameters
set_parameters, get_current_state, list_parameters
Programs & songs
list_programs, load_program, load_song
Backups
extract_backup, get_last_backup_location
Model-delegated design
Add a keyboard by implementing its device — the MCP tools stay generic.
Mock runner + broker
Electron mock device with a model-specific web UI; an MCB broker shares ports across sessions.
Quickstart

Up and running

# install & build
npm install
npm run build

# start the connections broker
npm run mcb

# optional: Electron mock device (no hardware needed)
npm run mock:runner
In the pipeline

Where it fits

Audio→Analysis→Agent→MIDI→Synth

keyboards-mcp is the final stage — it applies the matched sound to your hardware synth over MIDI.
