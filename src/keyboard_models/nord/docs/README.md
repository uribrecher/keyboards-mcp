# Nord Electro 5 documentation

This model's MIDI CC mapping is derived from the official *Nord Electro 5 User
Manual*, © Clavia DMI AB. That manual is **not redistributed in this repository**.
Download it from Nord's official downloads page:

- **Nord Electro 5 manuals** — https://www.nordkeyboards.com/downloads/manuals

The notes in this directory (`midi-cc-comparison.md`, `program-bit-layout.md`) are
our own analysis derived from that manual and from inspection of `.ne5p` program
files.
